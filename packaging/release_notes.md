### 내려받기

| 운영체제 | 파일 |
| --- | --- |
| macOS — **Apple Silicon(M1 이후) 전용** (인텔 맥 미지원) | `{dmg}` |
| Windows 10/11 (64비트) | `{setup}` |

나머지 `*.tar.*` 파일은 설치 파일에 든 ffmpeg 정적 빌드의 GPL 대응 소스 코드입니다 (설치에는 필요 없음).
자세한 내용은 설치 파일 안의 `THIRD_PARTY.txt` 를 보세요.

### 맥에서 처음 열 때

1. dmg 를 열고 `youtube-edit` 을 `Applications`(응용 프로그램) 폴더로 끌어 놓습니다.
2. 처음 열면 "확인되지 않은 개발자" 경고가 뜹니다. **시스템 설정 › 개인정보 보호 및 보안** 으로 가서
   아래쪽 "youtube-edit 이(가) 차단되었습니다" 옆의 **그래도 열기** 를 누릅니다.
   최신 macOS 에서는 우클릭 › 열기만으로는 열리지 않으니 이 경로를 써 주세요.

### 윈도우에서 설치할 때

1. `{setup}` 을 실행하면 SmartScreen "Windows의 PC 보호" 창이 뜹니다. **추가 정보** → **실행** 을 누릅니다.
2. WebView2 런타임이 없으면 설치 프로그램이 함께 설치합니다 (인터넷 연결 필요).

### 업데이트할 때

새 버전을 설치할 때마다 위의 경고(맥 "그래도 열기", 윈도우 SmartScreen)를 한 번 더 넘겨야 합니다.
맥은 응용 프로그램 폴더의 앱을 새 버전으로 바꿔 끌어 놓고, 윈도우는 새 설치 파일을 같은 위치에 다시 설치합니다.
처음 실행할 때는 음성 인식 모델(약 2.8GB)을 내려받습니다.
