# 끼워 넣은 영상 옮기기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 끼워 넣은 영상(과 그 안에 끼운 영상까지 한 덩어리)을 타임라인 띠 끌기나 머리 줄 `옮기기` 버튼으로 다른 자리로 옮기고, 넣기·옮기기의 자리 맞춤을 "영상 경계 우선" 으로 고친다.

**Architecture:** 순수 계산(자리 맞춤·조각 재배치·편집 시간 옮기기)은 `app/sequence.py`, 화면용 같은 자리 맞춤은 `app/ui/timeline.js`(`TL`). `Api.move_clip` 은 `remove_clip`/`_insert_file` 과 같은 잠금·`_restructure`·`rejudge` 흐름을 쓴다. 화면은 `app/ui/app.js` 의 `clp` 모듈(띠 끌기·머리 줄 버튼)만 고친다. 파이프라인은 손대지 않는다.

**Tech Stack:** Python 3 (pytest), vanilla JS (node 로 `TL` 테스트), pywebview.

**Spec:** `docs/superpowers/specs/2026-11-09-clip-move-design.md`

## Global Constraints

- 시간은 모두 "이어 붙인 영상의 초", 원본 프레임 격자(`fps`)에 맞춘다. 비교 오차는 `sequence.EPS` (1e-6).
- A(`clip == "main"`)는 옮기거나 제거할 수 없다.
- 옮기기는 전사를 다시 하지 않는다 (다시 판정만, 파일별 캐시).
- 화면 문구 (그대로):
  - 버튼: `옮기기`, `제거` (영상 탭의 `빼기` 도 `제거` 로)
  - 말풍선 `옮기기`: "고른 영상을 지금 재생 위치로 옮깁니다"
  - 말풍선 `옮기기`(재생 위치가 그 영상 안): "재생 위치를 고른 영상 밖으로 옮기세요"
  - 말풍선 `제거`: "고른 영상을 결과에서 뺍니다 (실행 취소로 되돌릴 수 있음)"
  - 말풍선 (두 버튼, 선택 없음): "타임라인 띠나 영상 탭에서 끼워 넣은 영상을 고르세요"
- 끌기 시작 기준: 4px.
- 테스트: `.venv/bin/python -m pytest` 전체가 통과해야 각 태스크 끝.

## Review Focus

1. 영상 경계 근처 잘린 구간에 놓기/넣기 — 이웃 영상이 갈라지지 않고 경계에 붙어야 한다 (Task 1 `test_snap_prefers_piece_boundary_in_cut`, Task 3 `test_add_clip_near_boundary_snaps_to_boundary`).
2. 다른 영상 안에 끼운 C 를 밖으로 옮기기 — 남은 B1·B2 가 한 조각으로 합쳐져야 한다 (Task 3 `test_move_nested_out_merges_parent`).
3. 덩어리 경계에 걸친 이미지·직접 자르기 — 이미지는 제자리에서 줄고, 자르기는 경계에서 나뉘어 안쪽만 따라간다 (Task 2 `test_shift_for_move_straddlers`).
4. 실행 취소 한 번으로 옮기기 전과 완전히 같아짐 (조각·편집·자막 수정) (Task 3 `test_move_undo_restores_everything`).
5. 띠를 짧게 눌러 고르기 — 4px 이하 움직임은 옮기기가 아니라 고르기 (Task 5 수동 확인 항목 + `TL.isDrag` 테스트).

  - `sequence.snap_at(t: float, cuts: list[tuple[float, float]], bounds: list[float], fps: float, total: float) -> float` — 격자 맞춤 → [0, total] → 잘린 구간 (a, b) 안이면: 그 안(a < x < b, 열린 구간)에 경계가 있으면 t 에 가장 가까운 경계(같으면 앞쪽), 없으면 a 를 격자에 맞춘 값.

  - `TL.isDrag(dx, dy)` — `Math.hypot(dx, dy) > 4`.

def test_piece_bounds_and_block_span():
    ps = [P("a", "main", 0, 4), P("b", "B", 0, 1), P("c", "C", 0, 2), P("d", "B", 1, 3), P("e", "main", 4, 10)]
    assert S.piece_bounds(ps) == [4, 5, 7, 9]
    assert S.block_span(ps, "B") == (4, 9)
    assert S.block_span(ps, "C") == (5, 7)
    assert S.block_span(ps, "X") is None

def test_snap_prefers_piece_boundary_in_cut():
    fps = 30.0
    # 경계 5.0 이 잘린 구간 (4.6, 5.5) 안 → 가장 가까운 경계
    assert S.snap_at(5.3, [(4.6, 5.5)], [5.0], fps, 10) == 5.0
    # 경계 없는 잘린 구간 → 구간 시작 (지금 넣기 규칙)
    assert S.snap_at(3.0, [(2.6, 3.4)], [5.0], fps, 10) == pytest.approx(2.6)
    # 잘린 구간 밖 → 격자만
    assert S.snap_at(4.01, [], [], fps, 10) == pytest.approx(4.0)
    # 범위 밖은 [0, total]
    assert S.snap_at(-1, [], [], fps, 10) == 0 and S.snap_at(99, [], [], fps, 10) == 10
    # 한 잘린 구간 안 경계 둘 → t 에 가까운 쪽
    assert S.snap_at(6.9, [(4.5, 7.5)], [5.0, 7.0], fps, 10) == 7.0
```

**Interfaces:**
- Consumes: `block_span` (Task 1), 기존 `_rm_span`, `_ins_span`, `_convert`, `shift_for_remove`, `shift_for_insert`, `split_piece`.
- Produces:
  - `sequence.move_block(pieces: list, clip: str, t: float) -> tuple[list, float]` — t 는 **옮기기 전** 시각(이미 맞춘 값, 덩어리 밖). 덩어리 조각들을 빼고, 남은 목록의 `t2 = t if t <= s else t - d` 자리에 그 조각들을 순서대로 넣는다(그 자리가 조각 가운데면 `split_piece` 처럼 갈라 뒤쪽은 새 id). 반환 `(새 조각 목록, t2)`. 합치기(`_merge_pieces`)는 하지 않는다 — API 가 한다.
  - `sequence.shift_for_move(e: dict, s: float, end: float, t2: float) -> dict` — 덩어리 [s, end] 를 빼서 t2(옮긴 뒤 시각)에 넣을 때의 편집:
    - 바깥: `shift_for_insert(shift_for_remove(e, [(s, end)]), t2, d)`.
    - 안쪽: `_convert(e, [(s, end, t2)])` 의 `restored`·`range_ops`·`line_times`, 그리고 `overlays` 는 **[s, end] 안에 완전히 든 것만** `_convert` 해서 붙인다 (걸친 이미지는 바깥 규칙만).
    - `word_edits`·`word_styles` 는 그대로 복사 (stable 키는 API 가 옮김).

def test_move_block_after_and_before():
    ps = [P("a", "main", 0, 4), P("b", "B", 0, 2), P("e", "main", 4, 10)]
    out, t2 = S.move_block(ps, "B", 8)           # 뒤로: 8 - 2
    assert t2 == 6 and [(p["clip"], p["in"], p["out"]) for p in out] == \
        [("main", 0, 4), ("main", 4, 6), ("B", 0, 2), ("main", 6, 10)]
    out, t2 = S.move_block(ps, "B", 1)           # 앞으로
    assert t2 == 1 and [p["clip"] for p in out] == ["main", "B", "main", "main"]

def test_move_block_carries_nested():
    ps = [P("a", "main", 0, 4), P("b", "B", 0, 1), P("c", "C", 0, 2), P("d", "B", 1, 3), P("e", "main", 4, 10)]
    out, t2 = S.move_block(ps, "B", 10)
    assert t2 == 5 and [p["clip"] for p in out] == ["main", "main", "B", "C", "B"]

def test_shift_for_move_inside_follows():
    e = E(range_ops=[{"op": "cut", "start": 4.5, "end": 5.0}], line_times={"9:0": [4.25, 4.75]},
          overlays=[{"id": "in", "start": 4.125, "end": 4.875}], word_edits={"x": 1})
    r = S.shift_for_move(e, 4, 6, 7)             # 덩어리 4~6 → 옮긴 뒤 7 에서 시작
    assert r["range_ops"] == [{"op": "cut", "start": 7.5, "end": 8.0}]
    assert r["line_times"] == {"9:0": [7.25, 7.75]}
    assert [(o["start"], o["end"]) for o in r["overlays"]] == [(7.125, 7.875)]
    assert r["word_edits"] == {"x": 1}

def test_shift_for_move_straddlers():
    e = E(range_ops=[{"op": "cut", "start": 3, "end": 5}],          # 경계 4 를 넘음
          overlays=[{"id": "o", "start": 2, "end": 5}],              # 덩어리에 걸침
          restored=[[8, 9]])                                          # 바깥, 옮긴 자리 뒤
    r = S.shift_for_move(e, 4, 6, 7)             # 덩어리 길이 2, 빼면 8~9 → 6~7, 7 에 넣으면 그대로 6~7
    assert sorted((o["start"], o["end"]) for o in r["range_ops"]) == [(3, 4), (7, 8)]
    assert [(o["start"], o["end"]) for o in r["overlays"]] == [(2, 4)]   # 제자리에서 줄어듦
    assert r["restored"] == [[6, 7]]
```
