# 결과 화면 손보기: 자막 고치기 · 구간 직접 자르기 · 잡음/무음 세기

데스크톱 앱(`docs/superpowers/specs/2026-10-22-desktop-app-design.md`, 이하 "앱 스펙")의 결과 화면(앱 스펙 3.3)에
기능을 더한다. 앱 스펙의 원칙(렌더 없이 미리보기, "저장" 을 눌러야 파일을 만든다, CLI 기본 동작은 그대로)은 그대로 따른다.

## 1. 왜 만드는가 (사용자 말)

- 자막이 **한국어·영어가 섞인 구간**과 **사람 이름**에서 틀린다. 지금은 고칠 방법이 SRT 파일을 직접 여는 것뿐이다.
- 자막 **한 줄이 일찍 뜨거나 늦게 사라진다** (Whisper 단어 시간 ±0.5초 오차).
- 배경 잡음이 **덜 지워진다**. 계속 깔리는 소리(에어컨·팬)와 가끔 튀는 소리(키보드·차) 둘 다.
- 말 없는 구간이 **여전히 너무 많이 남는다**.
- 말이 꼬여 다시 말한 앞부분처럼 **원하는 구간을 직접 자르거나**, 자동으로 잘린 곳 일부를 **직접 살리고** 싶다.

### 1.1 실제 영상에서 확인한 것 (앱 작업 `a6007c0b3e70`, 야외 51초 영상)

- 말소리 중간값 -23.6dB, 말 없는 틈 대부분 -26 ~ -30dB. 무음 자동 기준이 상한 -30dB 에 걸렸고 틈이 그보다 시끄러워
  18곳·12.7초(영상의 1/4)가 안 잘렸다. 가장 긴 것은 35.8~40.5초 4.7초 (풍경 보여 주기 + 전사 안 된 아이 목소리 0.8초).
- 결론: 소리 크기 기준을 조정하는 것만으로는 이런 영상에서 거의 안 바뀐다. 말소리와 배경이 붙어 있어 기준을 올리면 말끝이 먹힌다.
  → "단어 없는 틈" 기준 단계가 필요하다 (3.4).

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 결과 화면에서 자막 어절을 눌러 바로 고친다. 같은 말 전부를 한 번에 바꾼다.
- 자막 줄의 시작·끝 시간을 고친다.
- 배경 잡음 제거 세기와 말 없는 구간 자르기 세기를 고른다.
- 구간을 직접 골라 자르거나 되살린다.
- 이 모든 것은 **전사를 다시 하지 않는다**. 저장할 때 SRT·mp4 안 자막·영상에 반영된다.

**비목표**
- 자막 줄 나누기·합치기, 자막 글꼴·위치·번인.
- 고친 자막 글자로 컷 판정을 바꾸는 것 (고친 말이 필러여도 잘림 여부는 그대로).
- 고친 이름·단어를 다음 영상에 기억하거나 Whisper 프롬프트에 넣는 것 (나중 일).
- 실행 취소(Undo) 스택. 되돌리기는 각 기능의 "원래대로" 로 한다.

**실패 조건 (동작해도 실패)**
- 옵션을 바꾸거나 앱을 다시 켰더니 고친 자막·직접 자른 곳이 사라진다.
- 고친 내용이 미리보기에는 보이는데 저장한 SRT·mp4 에는 없다 (또는 그 반대).
- CLI(`pipeline.py` 를 앱 옵션 없이 실행) 결과가 바뀐다.
- 잡음 세기를 바꿨다고 전사를 다시 한다.

## 3. 화면과 동작 (사용자 결정은 "사용자", 나머지는 설계자 판단)

### 3.1 자막 고치기 — 목록 탭 + 영상 위 자막 둘 다 (사용자, 시안 C)

- 결과 화면의 "잘린 곳" 목록 자리에 탭 두 개: `잘린 곳 N` · `자막 N줄`. 탭은 같은 자리를 나눠 쓴다 (설계자).
- **자막 탭**: 한 줄에 `시간  어절 어절 어절`. 줄의 시간을 누르면 그 줄 조금 앞부터 잘린 곳을 건너뛰며 재생한다
  (지금 `player.clip` 과 같은 동작). 어절을 누르면 그 자리가 입력칸으로 바뀌고, Enter 또는 바깥 클릭으로 확정,
  Esc 로 취소. 빈칸으로 확정하면 그 어절을 자막에서 뺀다 (설계자).
- **영상 위 자막**: 미리보기 영상 바로 아래(또는 위에 겹쳐)에 지금 시간의 자막 줄을 보여 준다. 재생 중엔 보기만 하고,
  멈춘 상태에서 어절을 누르면 자막 탭과 같은 방식으로 고친다 (사용자: "어느 쪽에서 고쳐도 같이 바뀜").
- 고친 어절은 초록(`--restored` `#2a9d5c`)으로 표시. 고친 어절에 "원래대로" 를 둔다 (입력칸 옆 작은 버튼, 설계자).
- 한 어절에 띄어쓰기를 넣어도 된다 (`에이피아이` → `API 를` 처럼). 자막에서는 그냥 그 글자로 나간다.
- 결과 영상에서 잘린 말은 자막 탭에 나오지 않는다 (자막에도 없으므로).

### 3.2 찾아 바꾸기 (사용자)

- 자막 탭 위에 `찾기 [   ] → [   ]  전부 바꾸기 · N곳`. 입력하는 동안 N 을 갱신하고 찾은 곳을 목록에서 강조한다.
- 찾기는 **어절 경계를 넘어** 맞춘다: 자막 줄 글자에서 공백을 무시하고 찾는다 (`에이피 아이` 두 어절도 `에이피아이` 로 찾힘, 설계자).
  찾는 범위는 한 자막 줄 안이다. 두 줄에 걸친 일치는 찾지 않는다 (설계자).
- 어절 일부만 맞으면 맞지 않은 글자는 남긴다 (설계자): `김영산이` 에서 `김영산`→`김영선` 이면 `김영선이`.
  여러 어절에 걸친 일치는 첫 어절이 [첫 어절의 맞지 않은 앞부분 + 바꾼 글자]를, 마지막 어절이 [맞지 않은 뒷부분]을 갖고,
  사이 어절은 빈 글자가 된다 (`에이피 아이를` → `API를` + 빈 어절).
- 이미 손으로 고친 어절도 바꾼 결과 글자 기준으로 찾는다.
- 대소문자는 구분한다 (설계자. 영어 이름 `Ian`/`ian` 구분이 필요할 수 있음).

### 3.3 자막 줄 시간 고치기 (사용자: "줄 하나만 일찍 뜨거나 늦게 사라짐", "이 방식이면 충분")

- 자막 탭에서 줄을 고르면(줄 시간을 누르면) 그 줄 아래에 `시작 0:12.4 [◀0.1][0.1▶][지금 위치로]   끝 0:15.0 [◀0.1][0.1▶][지금 위치로]  원래대로`.
- "지금 위치로" 는 재생기 현재 시간으로 맞춘다. 바뀐 시간은 영상 위 자막에 바로 반영된다.
- 앞 줄 끝보다 앞으로, 다음 줄 시작보다 뒤로 못 간다. 줄 길이는 최소 0.3초 (설계자).
- 시간은 **원본 영상 기준**으로 저장한다 (설계자). 미리보기 재생기가 원본 시간으로 돌기 때문이고, 저장할 때 잘린 곳을 빼서
  결과 영상 시간으로 바꾼다. 그 줄 시간 안이 잘린 곳에 걸치면 잘린 곳 경계로 줄인다.
- 사용자가 맞춘 시간은 고정이다 (설계자). `build_srt` 의 뒷처리(겹침 띄우기, 최소 길이, 영상 끝 자르기)는 고친 줄을 움직이지 않고
  이웃의 고치지 않은 줄만 맞춘다. 미리보기 자막과 저장 결과가 같아야 한다.

### 3.4 말 없는 구간: 슬라이더 0~100 (사용자: "볼륨 조절 같은 UI", 남는 게 너무 많다, 잘려도 되살리면 됨)

- 지금의 `유지/제거` 버튼을 **볼륨처럼 끌어서 조절하는 슬라이더**로 바꾼다 (사용자). 목업: `sliders-v2.html`.
- 양 끝 글자: `안 자름` · `최대한 자름`. 오른쪽 위에 지금 값(숫자).
- 슬라이더 아래 설명 한 줄이 값에 따라 바뀐다 (사용자가 고른 문구):
  - 0: `말 없는 구간을 자르지 않습니다`
  - 낮은 쪽~중간: `조용히 말 없는 구간 중 N초 이상만 자름 · 23곳 · −14초`
  - 중간~100 미만: `조금 시끄러운 말 없는 구간도 자름 (0.3초 이상) · 31곳 · −18초`
  - 100: `말 없는 구간은 소리가 있어도 전부 자름 · 41곳 · −27초`
  - `N곳 · −N초` 는 실제 판정 결과 (손을 뗀 뒤 다시 판정해 갱신). "지금" 같은 말은 붙이지 않는다 (사용자).
- 값과 판정의 대응 (설계자, 정확한 곡선은 빌더):
  - 0 → 끔 (`--silence off`).
  - 0~50 → 소리 크기 기준은 지금 그대로(자동 기준 포함), **최소 길이**를 1.0초 → 0.3초로 줄인다. **50 = 지금의 `제거`와 같은 결과**, 기본값.
  - 50~100 → 최소 길이 0.3초, **무음 기준을 올린다** (자동 기준의 상한 -30dB 과 "말소리 −6dB" 상한을 단계적으로 풀어
    말소리 중간값 쪽으로). 1.1 의 영상처럼 배경이 시끄러운 틈이 잡히기 시작한다.
  - 100 → 위에 더해 **받아쓰기된 단어가 없는 틈**은 0.3초 이상이면 소리가 있어도 자른다. 앞뒤 `silence_pad_sec` 는 남긴다.
    풍경 장면, 받아쓰기 안 된 사람 목소리도 잘린다 (사용자 승인: "필요하면 되살릴게").
    단어 판정은 무음 잇기와 같이 "자리가 의심스러운 단어"(`find_suspect_words`)는 틈을 막지 않는다.
    이렇게 잘린 곳은 `reason` 에 새 값(예: `gap`)을 써서 "잘린 곳" 목록에서 `말 없는 구간` 으로 보이되 구분된다.
  - 어느 값이든 단어(말소리) 안쪽은 자르지 않는다. 0~100 사이에서 값이 커지면 잘리는 곳이 줄지 않아야 한다 (단조).
- 끌어 움직이는 동안엔 숫자·설명 앞부분만 바뀌고, **손을 떼면** 캐시된 받아쓰기로 컷을 다시 판정한다 (앱 스펙 3.5 의 빠른 옵션).
  판정이 도는 중 또 움직이면 마지막 값만 판정한다.
- 옵션 저장은 숫자(0~100). 기존 작업의 `keep`→0, `remove`→50 으로 읽는다.
- CLI: `--silence on|off` 는 그대로(`on` = 50). 앱 전용 숨은 옵션으로 `--silence-level 0..100` 을 추가 (설계자).

### 3.5 배경 잡음 제거: 슬라이더 0~100 (사용자: "볼륨 조절 같은 UI", 덜 지워짐, 깔리는 소리·튀는 소리 둘 다)

- 지금의 `유지/제거` 버튼을 슬라이더로 바꾼다 (사용자). 양 끝 `끔` · `최대 (목소리 먹먹해질 수 있음)`.
- 설명 한 줄: 0 `원래 소리 그대로`, 낮은 쪽 `목소리를 살리며 가볍게 지움`, 높은 쪽 `계속 깔리는 소리·튀는 소리까지 세게 지움`.
- 값과 필터의 대응 (설계자, 정확한 값은 빌더가 실제 녹음(1.1 의 영상 포함)을 들어 보고 정함):
  - 0 → 필터 없음. 0~50 → `arnndn mix` 를 0 → 0.85 로. **50 = 지금의 `제거`와 같음**, 기본값.
  - 50~100 → `arnndn mix` 를 1.0 까지 올리고, 계속 깔리는 소리용 `afftdn` 등을 세기에 따라 더한다.
  - 값을 올리면 귀로 차이가 나야 한다 (10 단위로 들어서 구분되는 정도).
- **결과 오디오에만 적용**한다 (앱 스펙 3.5 와 같음). 분석용 오디오·무음 판정은 그대로다 → 받아쓰기를 다시 하지 않는다.
- **손을 떼면 미리보기 소리를 그 값으로 다시 만들어** 저장 전에 들어볼 수 있다 (설계자).
  영상은 다시 인코딩하지 않고 오디오만 바꿔 끼운다. 그동안 짧은 진행 표시, 재생 위치는 유지. 만드는 중 또 움직이면 마지막 값만.
  지금 미리보기는 `clean.wav` (분석용, rnnoise 0.85)를 쓰므로 50 과 같다.
- 옵션 저장은 숫자(0~100). 기존 작업의 `keep`→0, `remove`→50.
- CLI: `--render-denoise` 기존 값은 그대로. 앱 전용 숨은 옵션 `--render-denoise-level 0..100` 을 추가 (설계자).

### 3.6 구간 직접 자르기·되살리기 (사용자, 시안 C: 끌어서 잡고 재생하며 다듬기)

- 타임라인 막대를 끌면 구간이 잡힌다 (파란 테두리, 양 끝 손잡이로 조정). 막대를 그냥 누르면 지금처럼 그 위치로 이동.
- 구간이 있으면 막대 아래: `[여기서 시작] [여기서 끝]  0:15.3 ~ 0:26.5  [◀0.1][0.1▶](양 끝 각각)  [자르기] [되살리기] [취소]`.
  "여기서 시작/끝" 은 재생기 현재 시간으로 끝점을 정한다. 구간을 끌지 않고 "여기서 시작" 부터 눌러도 된다.
- **자르기**: 그 구간을 자른다. "잘린 곳" 목록에 `직접 자름` 으로 들어가고 거기서 "되살리기" 로 지울 수 있다.
- **되살리기**: 그 구간과 겹치는 자동 컷을 **그 구간만큼만** 살린다 (자동 컷 일부만 살리기 가능). 목록에는 지금처럼 되살림 표시.
- 프레임 격자에 맞추는 것은 저장 때 파이프라인이 한다 (cuts.json 은 start/end 초 기준).
- 직접 자른 곳·되살린 곳은 옵션을 바꿔 다시 판정해도 그대로 남는다 (지금 `job.restored` 와 같이).
- 직접 자른 구간 안의 말은 자막에서도 빠지고, 되살린 구간의 말은 자막에 돌아온다 (저장 결과 기준).
  판정은 **단어 가운데 시점**이 구간 안에 있느냐로 한다 (설계자). 자동 컷의 `words_idx` 규칙(시간 겹침으로 안 지움)은 그대로이고,
  이 시간 판정은 사용자가 직접 고른 구간에만 쓴다. 가운데 시점은 보정된 단어 시간(transcript.json 의 start/end) 기준.
- **되살리기 두 종류** (설계자):
  - "잘린 곳" 목록의 `되살리기` 버튼 = 지금과 같이 **그 컷 하나 전체** (절반 이상 겹침 판정, 옵션 재판정 뒤에도 같은 방식).
    기존 작업에 저장된 `restored` 는 이 종류로 읽는다.
  - 타임라인 구간 `되살리기` = **시간 그대로 그 구간만**. 자동 컷을 쪼갤 수 있다. 재판정 뒤에도 시간 그대로 적용.
- 직접 자르기와 구간 되살리기가 겹치면 **나중에 한 것이 이긴다** (설계자). 그래서 둘은 순서 있는 작업 기록
  (`[{op: cut|restore, start, end}]`)으로 저장하고, 자동 컷 위에 차례로 적용한다. "잘린 곳" 목록에서 직접 자른 곳을 되살리면
  그 기록 항목을 지운다.

### 3.7 저장과 상태

- 자막 수정·줄 시간·직접 자르기는 모두 **처리 없이 바로 반영**(되살리기와 같음)되고, `✓ 저장됨` 이었으면 `확인 대기` 로 돌린다.
- 영상별로 사용자 데이터 폴더(작업 저장소)에 남아 앱을 다시 켜도 그대로다.
- 저장하면 SRT 와 mp4 안 자막 트랙 모두 고친 자막으로 만든다.

## 4. 데이터와 파이프라인 (설계자 판단, 세부는 빌더)

- **어절 식별**: 전사의 `(seg, i)` (cuts.json `words_idx` 와 같은 키). 전사가 바뀌면(지문 불일치) 수정 내용은 버린다
  — `--apply-cuts` 와 같은 정책. 앱에서 이 경우 사용자에게 알린다.
- 작업(Job)에 추가: `word_edits {(seg,i): 글자}`, `line_times`(줄 시간 수정), `range_ops [{op, start, end}]`(3.6).
  기존 `restored` 는 컷 단위 되살리기로 그대로 쓴다.
- 줄 나누기·자막 계산은 **앱 프로세스가 `pipeline` 모듈을 바로 불러와** 같은 함수를 호출한다 (설계자). 클릭마다 서브프로세스를
  띄우지 않는다 (앱은 이미 `app/__main__.py` 에서 pipeline 을 불러온다). 저장 때 파이프라인도 같은 함수를 쓰므로 결과가 같다.
- **자막 줄 나누기를 앱과 파이프라인이 같게 계산**해야 한다. 지금 줄 나누기는 `build_srt` 안에 있고 결과 영상 시간을 기준으로 한다.
  앱이 같은 줄을 보여 주려면 줄 목록(각 줄의 어절 `(seg,i)` 목록과 원본 기준 시간)을 파이프라인이 만들어 내놓아야 한다.
  예: 분석(`--review`) 때 `<이름>.captions.json` 을 함께 쓰고, 컷이 바뀌면(되살리기·직접 자르기) 다시 계산.
  줄 시간 수정은 "줄 = 첫 어절 키" 로 식별한다 (설계자). 컷이 바뀌어 줄이 다시 나뉘면 첫 어절이 같은 줄에만 적용한다.
- 저장 때 파이프라인에 수정 파일을 넘긴다 (예: 숨은 옵션 `--subs-edits <json>`). 기본은 없음 → CLI 동작 그대로.
- 직접 자른 곳은 저장용 cuts(`save.cuts.json`, 지금 `save_cuts`)에 `reason: manual` 로 더한다.
- 테스트: 자막 수정 반영(SRT 글자·시간), 찾아 바꾸기(어절 경계 넘기), 줄 시간 제한, 말 없는 구간 슬라이더 값별 판정(50 = 기존 결과, 단조 증가),
  직접 자르기/부분 되살리기의 cuts 결과, 옵션 재판정 뒤 수정 유지, 기존 CLI cuts.json 불변.
